# PawCare

A responsive pet care website built with HTML, CSS and JavaScript. It showcases pet grooming, healthcare, food and boarding services, with news updates and pricing plans.

## Live Demo

**[Visit the website: fizaanwar.github.io/Pawcare](https://fizaanwar.github.io/Pawcare/)**

## Features

- Sticky navigation bar with smooth scrolling between sections
- Hero section with an arch-shaped image and floating info card
- Latest pet news cards with hover effects
- Services section with icon cards
- Three pricing plans with a highlighted "Most Popular" plan
- Dark footer with quick links, contact details and social icons
- Fully responsive layout for desktop, tablet and mobile
- Working hamburger menu on small screens

## Technologies Used

| Technology | Purpose |
|---|---|
| **HTML5** | Page structure and semantic markup |
| **CSS3** | Styling, CSS variables, Flexbox, Grid, animations and media queries |
| **JavaScript (Vanilla)** | Mobile menu toggle (DOM manipulation) |
| **Google Fonts** | Playfair Display and Nunito Sans typography |
| **Font Awesome 6** | Icons |
| **GitHub Pages** | Free hosting |

## Project Structure

```
Pawcare/

```

## Run Locally

1. Download or clone this repository:
   ```
   git clone https://github.com/fizaanwar/Pawcare.git
   ```
2. Open the folder.
3. Double-click `index.html` to open it in your browser.

No installation or build tools needed.

## Responsive Breakpoints

- **Desktop:** above 1024px
- **Tablet:** up to 1024px
- **Mobile:** up to 768px
- **Small mobile:** up to 480px
